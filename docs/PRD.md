# PRD ringkas

BLOK TAMAN adalah puzzle penempatan blok 8×8 portrait Android. Pemain memakai tiga blok dalam baki, menghapus baris/kolom penuh, dan mendapatkan Daun untuk dekorasi kosmetik.

Versi lokal: Santai offline, latihan daily deterministik, koleksi/taman dasar. Tidak ada iklan otomatis, energi, booster, gacha, transaksi nilai uang, atau leaderboard sintetis.

Target pengalaman: papan responsif, aturan deterministik, save setelah langkah Santai, dan UI aksesibel melalui tap-to-place.
